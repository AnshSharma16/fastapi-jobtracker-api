# FastAPI Job Tracker API

A backend API for tracking job applications, resumes, interview stages, and AI-powered job matching.

## Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker
- JWT Authentication

## Features
- User authentication
- CRUD job tracking
- Resume upload
- AI job matching
- REST API endpoints

## Status
🚧 In active development as part of a 60-day backend + AI automation roadmap.
